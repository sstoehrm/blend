# Example Skill

This is a placeholder skill. To add a real skill, create a new directory
under `plugins/skills/skills/<skill-name>/` containing a `SKILL.md` with
frontmatter (`name`, `description`) followed by the instructions Claude
should follow when the skill is invoked.
